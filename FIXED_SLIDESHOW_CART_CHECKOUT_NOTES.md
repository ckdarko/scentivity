# Fixed Scentivity Slideshow, Cart, and Checkout Update

This package fixes the JavaScript issue that prevented the slideshow and cart buttons from working.

Changes included:
- Restored working homepage slideshow functionality.
- Restored working Add to Cart and Cart button behavior.
- Payment methods are only Card, MoMo, and Pay on pickup.
- Removed Email from Buyer Information.
- Added Delivery fee (GH₵) for delivery orders.
- Cart totals show Subtotal, Delivery fee, and Total.
- Improved Pickup / Delivery buttons for phone screens.
- Added a buyer-facing slideshow description.
- Updated Paystack function so card and MoMo checkout can initialize without a buyer email field.

Deploy with Netlify → Deploys → Trigger deploy → Clear cache and deploy site.
