# Scentivity Color and Header Update

This version updates the public website styling to more closely match the supplied Scentivity logo colors.

## Changes made

- Updated the website palette to use hot pink, coral pink, soft blush, black, and white from the Scentivity brand/logo.
- Changed buttons, cards, section backgrounds, product filters, contact form, footer, and the back-to-top button to match the logo colors.
- Removed the floating/sticky header behavior. The header now sits normally at the top of the page and scrolls away with the page.
- Kept the back-to-top button so visitors can quickly return to the top after scrolling.
- Fixed the WhatsApp product inquiry button so each product opens a prefilled Scentivity WhatsApp message.

## Deployment

Upload the extracted files and folders to the existing GitHub repository, commit changes, and wait for Netlify to redeploy. Do not upload the ZIP file itself.
