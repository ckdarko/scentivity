Easy product updates

Add pictures, prices, and new scents without editing code.

  1. Deploy the website from GitHub to Netlify.
  2. Enable Netlify Identity and Git Gateway.
  3. Visit /admin, log in, and open Products.
  4. Click Add Product, upload a photo, enter the price, and publish.
